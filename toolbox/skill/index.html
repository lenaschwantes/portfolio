Claude Code skill

repo-scout

Ask Claude "is there a lib for X?" or "what can I use to build Y?" and it searches this library and live GitHub before answering, instead of suggesting tools from memory.

Install

mkdir -p ~/.claude/skills/repo-scout && cd ~/.claude/skills/repo-scout
curl -fO https://helena.schwantes.com.br/toolbox/skill/SKILL.md
curl -fO https://helena.schwantes.com.br/toolbox/skill/scout.py

Needs Python 3. Live GitHub search also needs the GitHub CLI, logged in.

Try it

python ~/.claude/skills/repo-scout/scout.py --tools "pdf|merge" --top 3

Or just ask Claude Code for a tool. The skill kicks in on its own.

Files
